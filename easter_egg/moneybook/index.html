가계부 한 달 기준

한 달은 시작일부터 다음 시작일 전날까지이고, 이름은 시작하는 달로 붙입니다(예: 9/22~10/19 = 9월). 20일이 수요일이면 화요일(19일)로 잡습니다. 내역·예산·지출 분석이 모두 이 기준을 따르며, 저장된 내역은 바뀌지 않습니다.

캡처 인식 설정

claude.ai 안에서 열려 있어 API 키 없이 캡처를 읽습니다.

Anthropic API 연결 캡처 인식

Claude Console(platform.claude.com) → Settings → API keys에서 만듭니다. 키는 이 브라우저에만 보관되고 api.anthropic.com으로만 전송되며, 저장소(GitHub)에는 들어가지 않습니다.

GitHub 자동 저장

claude.ai 안에서는 보안 정책 때문에 GitHub로 직접 보낼 수 없습니다. 내 컴퓨터(저장소 폴더에서 로컬 서버)나 GitHub Pages에서 열면 이 기능을 쓸 수 있습니다. 그때까지는 '백업·옮기기'의 JSON 백업을 쓰세요.
켜 두면 저장할 때마다(내역 추가·수정·삭제, 예산 저장, 목표·평가, 설정 변경) 몇 초 뒤 data/household-book.json과 data/transactions.csv를 커밋 하나로 저장소에 올립니다. 여러 번 연달아 저장하면 한 번으로 묶습니다.
GitHub → Settings → Developer settings → Fine-grained tokens에서 만듭니다. Repository access는 이 저장소만, Permissions는 Contents: Read and write만 주세요. 토큰은 이 브라우저에만 보관되고 api.github.com으로만 전송됩니다.
