# 가계부

인터넷뱅킹·카드앱의 거래내역 캡처를 올리면 날짜, 사용처, 금액, 분류를 읽어 통장별로 기입하는 개인 가계부입니다. `index.html` 파일 하나로 동작하고, 서버나 데이터베이스가 필요 없습니다.

이 저장소는 비공개(private)이며, 앱 코드와 함께 2026년 3월~9월 가계부 데이터(내역 443건), 네이버 가계부 원본 내보내기 파일, 10월 예산안 자료를 `data/` 폴더에 담고 있습니다.

## 저장소 구성

  budget-plan/

| 통장 | HeyYoung카드, 노리1, 노리2, 나라사랑우대통장, 삼성증권, 주택청약 종합저축(저축 통장: 주택청약) |

## 실행

비공개 저장소의 데이터를 그대로 쓰려면 **내 컴퓨터에서 실행**하는 방법을 권합니다.

```bash
git clone https://github.com/<사용자명>/<저장소명>.git
cd <저장소명>
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000`을 엽니다. 이 브라우저에 아직 데이터가 없으면 화면 위에 "저장소의 data/household-book.json(내역 443건)을 찾았습니다" 안내와 **불러오기** 버튼이 나옵니다. 누르면 내역, 통장, 카테고리, 규칙, 예산이 한 번에 들어옵니다.

`index.html`을 더블클릭해서 열면 브라우저 보안 정책 때문에 `data/` 파일을 자동으로 읽지 못합니다. 이때는 설정 → 백업·옮기기 → **JSON 백업 불러오기**로 `data/household-book.json`을 직접 고르면 됩니다.

### GitHub Pages를 쓸 경우 주의

- GitHub 무료 플랜에서는 비공개 저장소로 Pages를 켤 수 없습니다. Pro·Team·Enterprise 플랜이 필요합니다.
- 유료 플랜에서 켜더라도, Enterprise Cloud의 비공개 Pages 설정이 아니면 사이트는 인터넷에 공개됩니다. 이 경우 `https://<사용자명>.github.io/<저장소명>/data/household-book.json` 주소로 금융 데이터가 그대로 노출됩니다.
- Pages를 꼭 써야 하면 `data/` 폴더를 다른 비공개 저장소로 옮기거나 Pages용 브랜치에서 빼고 배포하세요.

## 캡처 인식용 API 키 넣기

claude.ai 밖(내 컴퓨터, GitHub Pages)에서 캡처를 읽으려면 본인의 Anthropic API 키가 필요합니다. claude.ai 아티팩트판에서는 키 없이 동작합니다.

### 1. 키 발급

1. [Claude Console](https://platform.claude.com)에 로그인합니다(계정이 없으면 만듭니다).
2. **Settings → API keys**로 갑니다.
3. **Create key**를 누르고 이름(예: `household-book`)을 붙여 만듭니다.
4. `sk-ant-`로 시작하는 키가 **한 번만** 표시되니 바로 복사해 둡니다. 잃어버리면 새로 만들어야 합니다.
5. API는 선불 크레딧으로 과금되므로 Console의 결제(Billing) 메뉴에서 크레딧을 충전해 두어야 요청이 처리됩니다.

### 2. 앱에 넣기

1. 앱 위쪽 메뉴에서 **설정** 탭을 엽니다.
2. **Anthropic API 연결** 카드의 **API 키** 칸에 복사한 키를 붙여 넣습니다.
3. **모델** 칸은 비워 두면 `claude-sonnet-5-5`를 씁니다. 다른 모델을 쓰려면 모델 이름을 적습니다.
4. **이 브라우저에 기억**을 켜 둔 채(기본값) **키 적용**을 누릅니다.
5. **연결 확인**을 누르면 키와 모델을 실제로 확인합니다. "연결되었습니다. … 모델로 캡처를 읽을 수 있습니다."가 나오면 끝입니다. 이제 **입력** 탭에서 캡처를 넣고 **캡처 읽기**를 누르면 됩니다.

연결 확인은 `GET https://api.anthropic.com/v1/models/<모델>`로 모델 정보만 조회하므로 사용료가 들지 않습니다. 실패하면 이유를 한 줄로 보여 줍니다(키가 틀림 401, 권한 없음 403, 모델 이름을 찾지 못함 404, 요청 과다 429, 네트워크 오류).

### 브라우저 기억 방식

포트폴리오 사이트 admin의 GitHub 토큰 설정(`admin-edit.js`)과 같은 방식입니다.

| 이 브라우저에 기억 | 저장 위치 | 남아 있는 기간 |
|---|---|---|
| 켬(기본) | localStorage `hb-apikey` | 이 브라우저에서 지우기 전까지. 다음에 열어도 다시 넣을 필요 없음 |
| 끔 | sessionStorage `hb-apikey` | 이 탭을 닫을 때까지. 공용 PC용 |

- 키를 읽을 때는 sessionStorage를 먼저 보고 없으면 localStorage를 봅니다. 키를 적용할 때마다 두 곳을 비운 뒤 고른 한 곳에만 넣습니다.
- 카드 아래 상태 줄에 "키 적용됨 · 이 브라우저에 기억됨 · …끝 4자리"처럼 현재 상태가 나옵니다.
- **키 지우기**를 누르면 두 곳에서 모두 지웁니다.
- 키는 저장소 파일, `data/household-book.json` 백업, CSV 어디에도 들어가지 않습니다. 기기나 브라우저를 바꾸면 그곳에서 한 번 다시 넣으면 됩니다.

### 키를 저장소에 넣지 않는 이유

비공개 저장소라도 키를 커밋하지 마세요.

- 키가 담긴 파일을 Pages로 배포하면 위에서 설명한 대로 누구나 받아 볼 수 있고, 사용료는 키 주인에게 청구됩니다.
- 커밋 기록에 한 번 들어간 키는 파일을 지워도 기록에 남습니다.
- 실수로 커밋했다면 Console에서 그 키를 바로 비활성화하고 새 키를 만드세요.

### 캡처를 보내는 방식

- 이미지는 긴 변 1800px, JPEG로 줄인 뒤 4장씩 나눠 `https://api.anthropic.com/v1/messages`로 보냅니다. 브라우저에서 API를 직접 부르기 위해 `anthropic-dangerous-direct-browser-access` 헤더를 씁니다.
- 인식 결과는 확인표에서 보고 저장하세요. 연도가 없는 날짜는 올해로, 오늘보다 뒤면 작년으로 처리합니다.

## 기능

| 탭 | 하는 일 |
|---|---|
| 입력 | 통장을 고른 뒤 캡처 여러 장을 끌어 놓거나 붙여 넣으면 거래를 읽어 확인표로 보여 줌. 고친 뒤 저장. 직접 입력도 가능 |
| 내역 | 월별 목록, 통장·구분·분류·검색 필터, 수정·삭제, 그 달의 지출 평가 한 줄 |
| 예산 | 대분류·소분류별 월 예산, 고정/변동 구분, 세부 메모, 예상 수입 대비 남는 돈, 그 달의 지출 목표 한 줄 |
| 지출 분석 | 월별/연도별 전환. 카테고리별 지출(소분류로 들어가기), 예산 대비 지출, 월별 추이 표(가로 스크롤), 수입·지출, 일별 누적, 통장별 소형 차트, 자주 쓴 곳 TOP 10, 소분류 상세, 그 달의 목표·평가 |
| 통장 | 통장별 누적 수입·지출·잔액, 잔액 맞추기, 저축 통장 지정(그 통장으로 보낸 이체를 저축 실적으로 집계) |
| 설정 | 카테고리 편집(이름을 바꾸면 기존 내역·예산·규칙도 함께 바뀜), 자동 분류 규칙, Anthropic API 연결(브라우저 기억·연결 확인), 네이버 가계부 가져오기, JSON 백업 |

캡처에서 읽은 거래의 분류는 다음 순서로 정합니다.

1. 설정의 자동 분류 규칙(사용내역에 키워드가 들어 있으면 그 분류, 위에서부터 먼저 맞는 규칙)
2. 과거 내역에서 같은 가맹점에 가장 많이 쓴 분류(그 분류가 60% 이상일 때)
3. 위 둘이 없으면 모델이 고른 분류

이미 있는 내역과 날짜·금액·통장이 같은 거래는 '중복 의심'으로 표시하고 저장 대상에서 빼 둡니다. 본인 통장 사이의 이체는 지출이 아닌 '이체'로 따로 기록합니다.

## 데이터 저장과 백업

| 실행 환경 | 저장 위치 | 캡처 인식 |
|---|---|---|
| 내 컴퓨터, GitHub Pages | 브라우저 localStorage(키 `hb-local`) | 본인 API 키 필요 |
| claude.ai 아티팩트 | claude.ai 아티팩트 저장소 | 추가 설정 없이 사용 |

같은 파일이 실행 환경을 스스로 판단해 저장 방식을 고릅니다. localStorage는 브라우저와 기기마다 따로이며, 브라우저 데이터를 지우면 함께 지워집니다.

앱에서 입력한 내용을 저장소에도 남기려면:

1. 설정 → 백업·옮기기 → **JSON 백업 내려받기**
2. 내려받은 `household-book-backup-YYYY-MM-DD.json`을 `data/household-book.json`에 덮어쓰기
3. 커밋·푸시

```bash
git add data/household-book.json
git commit -m "가계부 데이터 백업 (YYYY-MM-DD)"
git push
```

다른 기기나 claude.ai판으로 옮길 때는 옮길 쪽에서 **JSON 백업 불러오기**로 이 파일을 고릅니다. 불러오면 그 브라우저에 있던 데이터는 백업 내용으로 모두 바뀝니다.

## 네이버 가계부 가져오기

네이버 가계부에서 내려받은 `지출현황`, `수입현황` 엑셀 파일(.xls)을 그대로 넣거나, 여러 파일을 묶은 .zip을 넣습니다(설정 → 네이버 가계부 파일 가져오기). 시트의 `날짜·사용처·사용내역·현금·카드·출금통장·분류` 열과 `날짜·내역·금액·입금통장·분류` 열을 읽고, 처음 보는 통장과 분류는 자동으로 추가합니다. 날짜·내용·금액·통장이 같은 내역은 건너뛰므로 같은 파일을 두 번 넣어도 중복되지 않습니다. `data/naver-export/`의 14개 파일(408건)로 확인했습니다.

## 백업 파일 구조

```json
{
  "app": "household-book",
  "version": 1,
  "exportedAt": "2026-11-01T11:10:00.000Z",
  "settings": {
    "ownerName": "",
    "accounts": [{ "name": "통장 이름", "bank": "", "saving": "주택청약" }],
    "expCats": { "식비": ["주식", "커피/음료"] },
    "incCats": { "주수입": ["급여"] },
    "rules": [{ "kw": "쿠팡", "t": "e", "cat": "생활용품", "sub": "기타" }]
  },
  "budgets": {
    "byMonth": { "2026-10": { "식비": 223900, "식비>주식": 83900 } },
    "income":  { "2026-10": 1000000 },
    "notes":   { "2026-10": { "식비>주식": "세부 내역" } },
    "fixed":   { "식비>주식": true },
    "goals":   { "2026-10": "이번 달 지출 목표" },
    "reviews": { "2026-10": "이번 달 지출 평가" }
  },
  "months": {
    "2026-10": { "items": [
      { "id": "…", "t": "e", "d": "2026-10-05", "memo": "쿠팡", "amt": 13900,
        "acc": "통장 이름", "cat": "생활용품", "sub": "기타", "src": "capture" }
    ] }
  }
}
```

`t`는 `e`(지출), `i`(수입), `x`(이체, 받는 통장은 `to`)입니다. `src`는 입력 경로(`naver`, `capture`, `manual`, `adjust`)입니다. 환불은 음수 지출로 저장합니다. 수입 분류 `전월이월`은 시작 잔액용이라 수입 집계에서 뺍니다. 지출 분류 `저축`은 지출 분석에서 빼고 예산 실적에만 넣습니다.

## 알려진 제약

- 기기 간 동기화는 없습니다. 휴대폰과 PC에서 같이 쓰려면 JSON 백업으로 옮겨야 합니다.
- 캡처 인식 정확도는 캡처 화질과 은행 앱 화면 구성에 따라 다릅니다. 스크롤하며 찍은 캡처의 겹친 거래는 한 번만 넣지만, 같은 날 같은 가게에서 같은 금액을 두 번 쓴 경우 묶음 경계에서 한 건으로 합쳐질 수 있습니다.
- 데스크톱(1280px), 태블릿(820px), 휴대폰(390px) 너비의 Chromium에서 확인했습니다. Safari와 Firefox는 확인하지 않았습니다.
- 통장이 지정되지 않은 내역이 2건 있습니다(2026-05-04 온다택시 13,700원, 2026-07-20 HMG 택시 드라이브 27,633원). 내역 탭에서 수정할 수 있습니다.
